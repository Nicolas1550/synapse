# Publicación SYNAPSE 22

1. Extraer el ZIP en carpeta vacía.
2. Ejecutar `npm ci`, `npm run verify`, `npm run build`.
3. Publicar en Vercel e inspeccionar las 22 tarjetas de Project DNA y los filtros.
4. Verificar demos externas, GitHub y abrir las imágenes a tamaño completo.
5. Verificar responsive, núcleo 3D, recruiter mode y archivo de CV.

La compilación debe verificarse antes de subir a producción; las imágenes y URLs externas no prueban que cada servicio esté funcionando.
